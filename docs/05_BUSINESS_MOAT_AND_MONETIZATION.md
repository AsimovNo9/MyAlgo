# Business, Moat & Monetization

## Business hypothesis

A plausible paid product is persistent, user-controlled recommendation infrastructure rather than another feed.

Potential paid value:

- persistent personal graph
- richer explanation/history
- multiple modes
- cross-device synchronization
- additional connectors
- advanced counterfactuals
- optional privacy-preserving enrichment

Pricing should be validated rather than assumed.

## What is not a moat

These are relatively copyable:

- browser extension
- basic LLM classification
- embeddings
- vector search
- generic filtering
- simple ranking formulas

## Potential defensibility

Potentially stronger assets include:

1. durable personal graph/history, subject to privacy and retention constraints
2. high-quality graph editing UX
3. explanation/trust interaction
4. connector ecosystem
5. portable graph protocol
6. accumulated product knowledge about corrections and graph editing

None is a moat until users demonstrate durable value.

## Revenue validation

Run a real offer rather than asking only hypothetical willingness-to-pay questions.

Track:

- install → activation
- activation → first useful explanation
- graph corrections
- D7/D14 retention
- empty-feed rate
- replacement success
- willingness to pay
- cost per active user

Do not scale infrastructure before retention and value are demonstrated.
